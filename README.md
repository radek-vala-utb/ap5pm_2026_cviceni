# AP5PM 2026 – cvičení

Výukové materiály ke cvičením předmětu Programování mobilních aplikací.

Kurz používá následující technologický základ:

- Node.js 26,
- Angular 22,
- Ionic 9,
- Capacitor 8.5,
- TypeScript 6.

Soubor `.nvmrc` v kořeni repozitáře určuje Node.js 26. Pokud používáte `nvm`, po naklonování repozitáře stačí v jeho kořeni spustit `nvm install` a `nvm use`.
